# End-to-end adviser

CP-07 adds the application orchestration boundary for request compilation, candidate retrieval, constrained construction, evaluation, and evidence-bound explanation.

Clarification and unsupported results stop before downstream work. Every successful build creates an immutable content-addressed deck version. Lock, exclude, relax, and rerun operations create child versions; prior specifications and evidence remain unchanged. Version comparison reports metric deltas.

Every explanation must cite evidence returned by retrieval or evaluation. Unknown, empty, or model-memory-only evidence references fail the workflow rather than becoming user-visible claims.
